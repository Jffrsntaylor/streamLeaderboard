# Stream Leaderboard

Dante's first website.

## What does what (the restaurant)
| Part | Folder / file | Restaurant job |
|---|---|---|
| HTML | `index.html` | The building: walls, rooms, signs |
| CSS | `css/` | Paint and decorations |
| JavaScript | `js/` | The waiter: reacts when you click |
| API | `api/` (added later) | The kitchen: you order, it sends back data. Secret keys stay here. |
| Pictures | `images/` | Posters on the wall |
| GitHub | this repo | Save game with a time machine |
| Azure | Static Web Apps | The land with a street address |

## Hosting
Azure Static Web Apps (Free) connected to this repo. Every push to `main` updates the live site.
